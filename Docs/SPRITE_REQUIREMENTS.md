# Требования к изображениям и анимациям

> **Проект:** Maze: Coins and Exit  
> **Стиль:** Horror pixel art, top-down view  
> **Дата:** 7 апреля 2026

---

## 1. Общие требования

### 1.1 Базовый размер сетки
Все спрайты привязаны к сетке **48×48 пикселей**. Предметы — **24×24**.

### 1.2 Стиль
- **Pixel art** — чёткие пиксели, без сглаживания
- **Horror-атмосфера** — тёмные тона, гниль, кровь, разрушение
- **Top-down вид** — персонажи видны сверху (как в Enter the Gungeon, Nuclear Throne)
- **Прозрачный фон** — все PNG с alpha-каналом
- **Единая палитра** — все спрайты используют общую цветовую палитру (см. раздел 7)

### 1.3 Формат
- PNG с прозрачностью
- Без мипмапов, без сжатия
- Каждый файл = один кадр анимации

### 1.4 Анимации — общее правило
**Ничего не статично.** Каждый объект в игре должен двигаться/анимироваться:

| Тип объекта | Правило анимации |
|-------------|-----------------|
| Игрок | Анимация ходьбы (ноги, покачивание тела) |
| Враги | Анимация ходьбы (шатание, хромание) |
| Монеты | Вращение или пульсация |
| Предметы | Пульсация или покачивание |
| Пули | Свечение, след |
| Дверь | Свечение (locked/unlocked) |
| Стены | Не анимируются (статичный тайл) |

## 2. Игрок — вооружённый человек

### 2.1 Размер
**48×48 пикселей**

### 2.2 Анимация ходьбы
- **4 кадра** на каждый цикл ходьбы (walk cycle)
- Ноги двигаются, тело слегка покачивается
- Оружие слегка покачивается при ходьбе
- Цикл: idle → step1 → step2 → step3 → step4 → idle

### 2.3 Направления
**4 направления × 5 кадров** (1 idle + 4 walk) = **20 файлов**:

```

player_up_walk_1.png
player_up_walk_2.png
player_up_walk_3.png
player_up_walk_4.png

player_down_idle.png
player_down_walk_1.png
player_down_walk_2.png
player_down_walk_3.png
player_down_walk_4.png

player_left_idle.png
player_left_walk_1.png
player_left_walk_2.png
player_left_walk_3.png
player_left_walk_4.png

player_right_idle.png
player_right_walk_1.png
player_right_walk_2.png
player_right_walk_3.png
player_right_walk_4.png
```

### 2.4 Визуал
- Военная форма (тёмно-зелёный/оливковый)
- Каска или шлем
- Автомат/дробовик в руках (виден сверху)
- Ботинки, брюки
- При ходьбе — ноги переставляются, оружие слегка двигается

### 2.5 Анимация заражения
- Отдельные кадры не нужны — реализуется через шейдер (красный tint + дрожание)
- Или через overlay-спрайт: `player_infected_overlay.png` (полупрозрачный красный слой)

### 2.6 Анимация смерти
- **6 кадров** последовательной анимации:
  1. Спотыкается (наклон назад)
  2. Падает на колени
  3. Опускается на землю
  4. Лежит неподвижно
  5. Лежит (тень/кровь)
  6. Лежит (затемнение)

```

player_death_6.png
```

### 2.7 Анимация стрельбы (опционально)
- 2 кадра отдачи оружия на каждое направление:
```

player_down_shoot.png
player_left_shoot.png
player_right_shoot.png
```

## 3. Враги — ужасные зомби

### 3.1 Размер
**48×48 пикселей**

### 3.2 Анимация ходьбы
- **4 кадра** на каждый цикл
- Шатающаяся, хромающая походка — не равномерная, а «рваная»
- Конечности двигаются неравномерно (зомби-стиль)
- Голова болтается

### 3.3 Варианты (5 цветовых схем)
Каждый вариант — отдельная палитра, одинаковая форма:

| # | Имя | Палитра | Глаза |
|---|-----|---------|-------|
| 1 | `zombie_green` | Зелёная гниль | Красные |
| 2 | `zombie_grey` | Серая гниль | Жёлтые |
| 3 | `zombie_purple` | Фиолетовая гниль | Розовые |
| 4 | `zombie_brown` | Коричневая гниль | Зелёные |
| 5 | `zombie_blue` | Синяя гниль | Оранжевые |

### 3.4 Файлы
**5 вариантов × 4 направления × 5 кадров** (1 idle + 4 walk) = **100 файлов**:

```
zombie_green_up_idle.png
zombie_green_up_walk_1.png
zombie_green_up_walk_2.png
zombie_green_up_walk_3.png
zombie_green_up_walk_4.png
...
(для каждого направления и каждого цвета)
```

### 3.5 Визуал (общий для всех вариантов)
- Ужасный-зомби, вид сверху
- Куски свисающей шкуры/мяса
- Гниющие участки на теле
- Жадные глаза (контрастные к палитре тела)
- Хромая походка (одна лапа повреждена)
- Зубы/клыки видны
- Кровь/слизь

### 3.6 Анимация попадания
- Отдельные кадры не нужны — белая вспышка через шейдер (0.15с)
- Или: `enemy_hit_flash.png` (белый overlay)

### 3.7 Анимация смерти
- **8 кадров** последовательной анимации:
  1. Спотыкается (потерял равновесие)
  2. Падает на бок
  3. Корчится на земле
  4. Затихает
  5. Лежит (лужа крови/слизи)
  6. Лежит (растворяется)
  7. Лежит (почти исчез)
  8. Кучка останков (исчезает)

```

zombie_death_2.png
zombie_death_3.png
zombie_death_4.png
zombie_death_5.png
zombie_death_6.png
zombie_death_7.png
zombie_death_8.png
```

## 4. Стены — ужасающие тайлы

### 4.1 Размер
**48×48 пикселей**

### 4.2 Типы стен (6 видов)
Каждый тип — бесшовный тайл (tileable), края совпадают с соседями:

| # | Тип | Описание | Файл |
|---|-----|----------|------|
| 1 | **Гнилой кирпич** | Треснувший кирпич с плесенью, тёмно-серый с зелёными пятнами | `wall_brick_rotten.png` |
| 2 | **Кровавый камень** | Каменная кладка с кровавыми потёками, тёмно-коричневый | `wall_stone_bloody.png` |
| 3 | **Ржавый металл** | Ржавые металлические панели, заклёпки, оранжевые потёки | `wall_metal_rusty.png` |
| 4 | **Гнилое дерево** | Гнилые доски, гвозди, тёмное дерево с грибком | `wall_wood_rotten.png` |
| 5 | **Кость и плоть** | Стена из костей и засохшей плоти, жуткий органический вид | `wall_bone_flesh.png` |
| 6 | **Тюремная решётка** | Металлические прутья, можно видеть темноту за решёткой | `wall_bars_prison.png` |

### 4.3 Варианты каждого типа (2–3 вариации)
Для разнообразия — каждый тип имеет 2–3 под-вариации:

```
wall_brick_rotten_a.png   (обычный)
wall_brick_rotten_b.png   (больше трещин)
wall_brick_rotten_c.png   (с дырой/отсутствующий кирпич)

wall_stone_bloody_a.png   (слегка запачкан)
wall_stone_bloody_b.png   (много крови)
wall_stone_bloody_c.png   (скол камня)

wall_metal_rusty_a.png    (лёгкая ржавчина)
wall_metal_rusty_b.png    (сильная коррозия, дыра)
wall_metal_rusty_c.png    (погнутая панель)

wall_wood_rotten_a.png    (обычные доски)
wall_wood_rotten_b.png    (сломанная доска)
wall_wood_rotten_c.png    (с грибком и плесенью)

wall_bone_flesh_a.png     (кости)
wall_bone_flesh_b.png     (плоть)
wall_bone_flesh_c.png     (кости + плоть + глаз)

wall_bars_prison_a.png    (обычная решётка)
wall_bars_prison_b.png    (погнутые прутья)
wall_bars_prison_c.png    (цепи на решётке)
```

**Итого: ~18 файлов стен**

### 4.4 Визуальные требования к стенам
- **Ужасающие** — должны вызывать дискомфорт
- Тёмные тона — преобладают чёрный, тёмно-серый, тёмно-коричневый
- Акцентные цвета (редко): кровавый красный, гнилостный зелёный, ржавый оранжевый
- Текстура — неровная, потрескавшаяся, гниющая
- Бесшовность — края совпадают при тайлинге

### 4.5 LightOccluder
- Стены должны иметь чёткие границы для LightOccluder2D
- Непрозрачная область = стена, прозрачная = проход
- Occluder polygon совпадает с непрозрачной частью тайла

## 8. Технические требования для дизайнера

### 8.1 Формат файлов
- PNG с прозрачностью (alpha-канал)
- Без компрессии с потерями
- Без EXIF-метаданных
- Именование: `snake_case.png`

### 8.2 Сетка и выравнивание
- Все спрайты на сетке 48×48 (или 24×24 для предметов)
- Персонажи центрированы в кадре
- Нижняя часть персонажа = ноги/лапы = нижняя граница спрайта
- Оружие/аксессуары не выходят за пределы 48×48

### 8.3 Tileable стены
- Края тайла совпадают: левый = правый, верхний = нижний
- Проверить в Photoshop/GIMP через Filter → Other → Offset
-无缝 стыковка при повторении

### 8.4 Инструменты
- **Рекомендуемые:** Aseprite, LibreSprite, Pyxel Edit, GraphicsGale
- **Допустимые:** Photoshop, GIMP, Krita (с привязкой к пикселям)
- **Пиксель-перфект:** карандаш/brush 1px, без сглаживания

### 8.5 Чек-лист для дизайнера
- [ ] Все спрайты на прозрачном фоне
- [ ] Размеры соответствуют спецификации (48×48 или 24×24)
- [ ] Стены — tileable (бесшовные)
- [ ] Анимации имеют одинаковое количество кадров
- [ ] Персонажи центрированы
- [ ] Цветовая палитра единая
- [ ] Файлы названы по конвенции (snake_case)
- [ ] Нет полупрозрачных пикселей (или минимально) — pixel art должен быть crisp
- [ ] Экспорт в PNG без компрессии

## 9. Реализация в Godot

### 9.1 AnimatedSprite2D
Для анимированных объектов использовать `AnimatedSprite2D`:

```gdscript
# Player — AnimatedSprite2D с анимациями:
# - walk_up (4 кадра, speed: 8 fps)
# - walk_down (4 кадра, speed: 8 fps)
# - walk_left (4 кадра, speed: 8 fps)
# - walk_right (4 кадра, speed: 8 fps)
# - death (6 кадров, speed: 6 fps, oneshot: true)
```

### 9.2 Пульсация предметов
Для предметов с пульсацией — `Tween` в Godot (scale 1.0 → 1.1 → 1.0):

```gdscript
var tween = create_tween()
tween.set_loops()
tween.tween_property(self, "scale", Vector2(1.1, 1.1), 0.5)
tween.tween_property(self, "scale", Vector2(1.0, 1.0), 0.5)
```

### 9.3 Вращение монеты
Альтернатива: scaleX для имитации 3D-вращения:

```gdscript
var tween = create_tween()
tween.set_loops()
tween.tween_property(self, "scale:x", 0.1, 0.3)
tween.tween_property(self, "scale:x", 1.0, 0.3)
```

### 9.4 Шейдеры для эффектов
- Заражение игрока: красный tint + дрожание (shader)
- Попадание во врага: белая вспышка (shader или модulate = WHITE)
- Свечение предметов: Glow через CanvasLayer или Material

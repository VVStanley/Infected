## Требования к изображениям и анимациям

### 1. Общие требования

### 1.1 Базовый размер сетки
Все спрайты привязаны к сетке **48×48 пикселей**. Предметы — **24×24**.

### 1.2 Стиль
- **Pixel art** — чёткие пиксели, без сглаживания
- **Horror-атмосфера** — тёмные тона, гниль, кровь, разрушение
- **Top-down вид** — персонажи видны сверху (как в Enter the Gungeon, Nuclear Throne)
- **Прозрачный фон** — все PNG с alpha-каналом
- **Единая палитра** — все спрайты используют общую цветовую палитру (см. раздел 7)

### 1.3 Формат
- PNG с прозрачностью
- Без мипмапов, без сжатия
- Каждый файл = один кадр анимации

### 1.4 Анимации — общее правило
**Ничего не статично.** Каждый объект в игре должен двигаться/анимироваться:

| Тип объекта | Правило анимации |
|-------------|-----------------|
| Игрок | Анимация ходьбы (ноги, покачивание тела) |
| Враги | Анимация ходьбы (шатание, хромание) |
| Монеты | Вращение или пульсация |
| Предметы | Пульсация или покачивание |
| Пули | Свечение, след |
| Дверь | Свечение (locked/unlocked) |
| Стены | Не анимируются (статичный тайл) |

### 2. Игрок — вооружённый человек

### 2.1 Размер
**48×48 пикселей**

### 2.2 Анимация ходьбы
- **4 кадра** на каждый цикл ходьбы (walk cycle)
- Ноги двигаются, тело слегка покачивается
- Оружие слегка покачивается при ходьбе
- Цикл: idle → step1 → step2 → step3 → step4 → idle

### 2.3 Направления
**4 направления × 5 кадров** (1 idle + 4 walk) = **20 файлов**

### 2.4 Визуал
- Военная форма (тёмно-зелёный/оливковый)
- Каска или шлем
- Автомат/дробовик в руках (виден сверху)
- Ботинки, брюки
- При ходьбе — ноги переставляются, оружие слегка двигается

### 2.5 Анимация заражения
- Отдельные кадры не нужны — реализуется через шейдер (красный tint + дрожание)
- Или через overlay-спрайт: `player_infected_overlay.png` (полупрозрачный красный слой)

### 2.6 Анимация смерти
- **6 кадров** последовательной анимации

### 2.7 Анимация стрельбы (опционально)
- 1 кадр отдачи оружия на каждое направление

---

### 3. Враги — ужасные зомби

### 3.1 Размер
**48×48 пикселей**

### 3.2 Анимация ходьбы
- **4 кадра** на каждый цикл
- Шатающаяся, хромающая походка — не равномерная, а «рваная»
- Конечности двигаются неравномерно (зомби-стиль)
- Голова болтается

### 3.3 Варианты (5 цветовых схем)
Каждый вариант — отдельная палитра, одинаковая форма:

| # | Имя | Палитра | Глаза |
|---|-----|---------|-------|
| 1 | `zombie_green` | Зелёная гниль | Красные |
| 2 | `zombie_grey` | Серая гниль | Жёлтые |
| 3 | `zombie_purple` | Фиолетовая гниль | Розовые |
| 4 | `zombie_brown` | Коричневая гниль | Зелёные |
| 5 | `zombie_blue` | Синяя гниль | Оранжевые |

### 3.4 Файлы
**5 вариантов × 4 направления × 5 кадров** (1 idle + 4 walk) = **100 файлов**

### 3.5 Визуал (общий для всех вариантов)
- Ужасный-зомби, вид сверху
- Куски свисающей шкуры/мяса
- Гниющие участки на теле
- Жадные глаза (контрастные к палитре тела)
- Хромая походка (одна лапа повреждена)
- Зубы/клыки видны
- Кровь/слизь

### 3.6 Анимация попадания
- Отдельные кадры не нужны — белая вспышка через шейдер (0.15с)

### 3.7 Анимация смерти
- **8 кадров** последовательной анимации

### 4. Стены — ужасающие тайлы

### 4.1 Размер
**48×48 пикселей**

### 4.2 Типы стен (6 видов)

| # | Тип | Описание |
|---|-----|----------|
| 1 | **Гнилой кирпич** | Треснувший кирпич с плесенью |
| 2 | **Кровавый камень** | Каменная кладка с кровавыми потёками |
| 3 | **Ржавый металл** | Ржавые панели с заклёпками |
| 4 | **Гнилое дерево** | Гнилые доски с грибком |
| 5 | **Кость и плоть** | Органическая стена из останков |
| 6 | **Тюремная решётка** | Металлические прутья |

### 4.3 Варианты каждого типа (2–3 вариации)
- `a` — обычный
- `b` — повреждённый
- `c` — сильно повреждённый / дыра

### 4.4 Визуальные требования к стенам
- Ужасающие — должны вызывать дискомфорт
- Тёмные тона, акцентные цвета редко
- Бесшовность — края совпадают при тайлинге

### 4.5 LightOccluder
- Стены должны иметь чёткие границы для LightOccluder2D
- Occluder polygon совпадает с непрозрачной частью тайла

### 8. Технические требования для дизайнера

### 8.1 Формат файлов
- PNG с прозрачностью (alpha-канал)
- Без компрессии с потерями
- Без EXIF-метаданных
- Именование: `snake_case.png`

### 8.2 Сетка и выравнивание
- Все спрайты на сетке 48×48 (или 24×24 для предметов)
- Персонажи центрированы в кадре
- Нижняя часть персонажа = ноги/лапы = нижняя граница спрайта
- Оружие/аксессуары не выходят за пределы 48×48

### 8.3 Tileable стены
- Края тайла совпадают: левый = правый, верхний = нижний

### 8.4 Инструменты
- **Рекомендуемые:** Aseprite, LibreSprite, Pyxel Edit, GraphicsGale
- **Допустимые:** Photoshop, GIMP, Krita (с привязкой к пикселям)
- **Пиксель-перфект:** карандаш/brush 1px, без сглаживания

### 8.5 Чек-лист для дизайнера
- [ ] Все спрайты на прозрачном фоне
- [ ] Размеры соответствуют спецификации (48×48 или 24×24)
- [ ] Стены — tileable (бесшовные)
- [ ] Анимации имеют одинаковое количество кадров
- [ ] Персонажи центрированы
- [ ] Цветовая палитра единая
- [ ] Файлы названы по конвенции (snake_case)
- [ ] Нет полупрозрачных пикселей (или минимально) — pixel art должен быть crisp
- [ ] Экспорт в PNG без компрессии

### 9. Реализация в Godot

### 9.1 AnimatedSprite2D
Для анимированных объектов использовать `AnimatedSprite2D`.

### 9.2 Пульсация предметов
Для предметов с пульсацией — `Tween` в Godot (scale 1.0 → 1.1 → 1.0).

### 9.3 Вращение монеты
Альтернатива: scaleX для имитации 3D-вращения.

### 9.4 Шейдеры для эффектов
- Заражение игрока: красный tint + дрожание
- Попадание во врага: белая вспышка (0.15с)
- Свечение предметов: Glow через CanvasLayer или Material
